    Looking for Macs sharing on this Wi-Fi…
    Not showing up?
    • On the other Mac, open SyncAudio and click Start sharing.
    • Both Macs must be on the same Wi-Fi (not a guest network).
    • If macOS asked to let SyncAudio find devices on your network, choose Allow.
    • Or type the address the sharing Mac shows below.

    Add more Macs

    Any number of Macs can join. Each one just needs SyncAudio.

    Sharing this Mac

    Playing something but the bar isn't moving?
    • Allow SyncAudio to use the microphone. It only listens to BlackHole, never your real mic.
    • Check the Mac's sound output is BlackHole 2ch.
